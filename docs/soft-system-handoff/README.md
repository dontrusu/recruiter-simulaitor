# Soft System reference

`v0.33.0/soft-system.html` is the standalone export for Screen, Room, windows and
rejection feedback. Its README identifies each screenshot's viewport, state and limits;
the source snapshot includes the design tokens and licenses for the bundled fonts and
libraries. The capture scripts describe the original studio environment and are not
required to run the game.

`handoff-start-v0.1.0/preview.html` and its 1440×900 and 390×844 screenshots
are the separately approved reference for the neutral starting canvas, the complete
inert Shop row and empty Taskbar. Its example candidate and actions are not game rules.
Both exports are standalone and are not runtime dependencies of the game.

## Foundation slice comparison

Compared the game and approved start at 1440×900 in Chromium: both use a neutral
canvas, dark sans heading, compact monospace labels, and a centered, outlined review
window with a Vacancy above a white Application. The game retains its authored
Candidate and the existing three Reason choices and rewards until the next loop slice.
The old fixed side Shop, Screen geometry, footer, portrait and absent Taskbar remain
temporary differences for later slices; the review content and controls consequently
occupy different dimensions. The narrow-screen scaling, Room, window and motion states
are covered by their respective later slices rather than established by this comparison.

## Room and camera slice comparison

Chromium comparisons at 1440×900 and 390×844 used the start Room in the
v0.33.0 export and the game in Room view. The wall, lights, desk, Monitor,
keyboard, mouse and papers use the same 1600×900 Room coordinates; the live
Screen occupies the 800×500 aperture. The reference places its demonstration
toolbar above the Room; the game fits the Room in the full viewport with a small
development camera button. The game uses its authored content and the separately approved Shop and empty
Taskbar. The same narrow view scales the entire Room;
its text is correspondingly small, as agreed in the migration scope.

At the same sizes, the Screen view was compared with the approved start preview.
Both fit the complete composition and keep the review controls above the Taskbar.
The game retains its authored content, different header and portrait artwork. At
390×844 the text is small and the longer game header wraps; the separate mobile
adaptation remains outside the migration scope.

## Developer composition comparison

Compared full chaos in Chromium at 1440×900 against the v0.33.0 Screen and Room
screenshots. The eight open windows, their overlapping order, Talent Pool, and
Taskbar occupy corresponding parts of the Screen. All ten Room objects appear at
the handoff locations; they are inert demonstration art. The game uses its own
Candidate facts, portrait, counters, header and full Shop, and its development
controls sit outside the canvas. Its Room uses the full viewport instead of the
reference's toolbar. The demonstration Taskbar uses simplified window buttons
and omits the reference's fictional tray activity; window content is static,
including the warmth indicator. The review card is scaled and repositioned in
the preset, and typography and window details differ from the prototype. These
are observed differences for review, not new Upgrade mechanics or approval of
future progression.
