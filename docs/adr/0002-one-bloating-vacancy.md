# One bloatable vacancy instead of a new vacancy per stage

Progression is a single vacancy that grows absurd as requirements are added to it, rather than a new
vacancy introduced at each stage. The player's sense of change comes from role drift around that one
opening — the work turns mechanical, then caretaking, then ceremonial — not from changing employer,
role, or rank. This replaces the earlier "new absurd vacancy per stage" model, which tied progression
to staged roles we have since removed, and it keeps the satire pointed at one job description that
nobody can satisfy.
