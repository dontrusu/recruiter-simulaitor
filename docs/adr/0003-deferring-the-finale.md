# Defer the finale until a working game exists

The finale — Hiring Freeze plus an unending candidate — is deliberately not designed or built yet,
and the earlier three-endings model is suspended until then. A working game must exist first,
because the ending only lands if the loop it interrupts is already fun; designing it against an
unvalidated loop produces an ending that has to be thrown away. This is why the codebase has no
ending machinery and why the removed endings are not a bug to restore: the absence is the decision.
